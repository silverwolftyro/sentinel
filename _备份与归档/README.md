# _备份与归档 —— 历史档案区

> **这里不是源码。** 本目录用于存放**已经退出哨兵主线**的历史资产，
> 供考古、比对与写作参考，**不参与构建、不参与测试、不参与版本管理**。

---

## 1. 收录标准

一个目录/文件满足以下任一条件，就该被移进本目录：

| 条件 | 例子 |
| --- | --- |
| 已被主线取代的旧实现 | 旧版 GUI 巨物 `gui/app.py` |
| 外部项目的完整副本 | `dsh-speak-human工作区/`（早期插件工程） |
| 大体积的历史数据 | 旧 Agent 的完整会话记录 |
| 一次性调研的原始素材 | 从目标项目里扒下来的源码快照 |

**判据是「有没有人还会再读它」**，而不是「它是不是有价值」。
考古结论一旦写进 `_管理文档/文档与报告/versions/`，原件就不再需要留在主线视野里。

> ⚠️ 与 `回收站/` 的区别：这里的东西**有保留价值**，
> 只是已经不属于主线了；`回收站/` 里的东西是**确认没用的垃圾**。

## 3. 使用约定

- **只读**：归档内容一律不再维护，不再修复 bug，不再跟进上游；
- **不 import**：`src/` 下的任何模块都不得引用本目录里的代码；
- **不入库**：`.gitignore` 已排除本目录内容（保留本说明文件）；
- **可回收**：确认某个归档条目已无参考价值时，可直接删除 ——
  删除归档**不影响**哨兵任何功能。
