# sentinel.exe 命令行帮助

> 本文件是 `sentinel.exe --help` 的**纯文本帮助文档**。
> 打包产物在 `_构建与发布/dist/sentinel.exe`（**16.1 MB**），
> 复制到任何一台 Windows 上**双击就能跑** —— 不需要 Python、不需要装依赖。

## 二、四个最常用的场景

### 1. 第一次用（先看看长什么样）

```powershell
sentinel.exe
```

双击也行。会自动生成一段模拟日志、启动看板、打开浏览器。
**不接任何真实 Agent**，不会碰你的任何文件。

⚠️ 演示模式会**一直提醒你它是假的**（v2.2.2）：
看板顶栏挂一整条**红色横幅**、背景铺**红色斜条纹**、
左侧会话名是「**[演示] 默认会话**」；
终端大字报之后也会紧跟 6 行醒目说明，直接告诉你**怎么用真的**。

### 2. 挂机守夜（推荐姿势）

```powershell
sentinel.exe --agent codex "把 src/auth 里的登录逻辑重构一下并补测试" --keep-alive
```

- `--keep-alive`：Agent 跑完后**看板不关**，一直留到 Ctrl+C；
- 会话结束时自动生成《哨兵值守晨报》，
  落在 **exe 旁边的 `晨报归档/晨报-YYYY-MM-DD.md`**。

### 3. 多路同时守

```powershell
sentinel.exe --session-file sessions.json
```

```json
{
  "sessions": [
    {"id": "codex-a", "label": "Codex · 写脚本", "agent": "codex",
     "task": "在当前目录创建 hello.py 并运行它", "cwd": "D:/work"},
    {"id": "codex-b", "label": "Codex · 查日志", "agent": "codex",
     "task": "分析 logs 目录里的错误", "cwd": "D:/work"}
  ]
}
```

### 4. 审查一份已有的日志

```powershell
sentinel.exe --scan logs\agent_live.jsonl --task-goal "重构 auth 模块"
```

## 三、配置从哪来

| 位置 | 说明 |
| --- | --- |
| `<exe 旁边>/config/config.yaml` | **你的配置**。第一次运行自动从模板生成，可以直接改 |
| `<exe 旁边>/logs/` | 告警日志、Token 账单、守护者留痕 |
| `<exe 旁边>/晨报归档/` | 晨报 |
| 环境变量 | 云端模型的密钥 |

密钥**不要写进配置文件**（那东西虽然不入库，但仍会明文落在磁盘上）：

```powershell
$env:SENTINEL_LLM_API_KEY = "sk-..."     # 通用
$env:DEEPSEEK_API_KEY      = "sk-..."     # DeepSeek（按 base_url 自动识别）
```

按主机名自动识别的厂商：
`DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` / `KIMI_API_KEY` / `ZHIPU_API_KEY` /
`SILICONFLOW_API_KEY` / `DASHSCOPE_API_KEY` / `OPENROUTER_API_KEY` / `OPENAI_API_KEY`。

## 四、自己打包

```powershell
python -m pip install pyinstaller
python _构建与发布/scripts/build_exe.py
```

打包完会**自动自检**（跑一次 `--help`），
日志在 `_构建与发布/dist/build_exe.log`。

> ⚠️ 打包**成功 ≠ 能跑**。单文件程序最常见的翻车点是
> 「资源找不到」「动态导入漏了」，而这两种只有真跑一次才会暴露 ——
> 所以自检是**自动**的，别跳过。

## 五、安全边界（务必读完）

- 哨兵**绝不 kill 进程** —— 守护者模式下最多把进程**挂起**，
  而且随时可以在看板上【放行并忽略】，所有动作都留痕在 `logs/`；
- 哨兵**绝不替 Agent 改代码** —— 不改它的源码、配置、prompt、运行环境；
- **意图漂移与死循环只告警、不挂起** —— 那不是红线；
- 守护者默认**关闭** —— 权限必须小于用户，要显式开；
- 接云端模型 = 允许被审查的日志内容**离开本机**
  （密钥与个人信息在送出前会先脱敏）。

### v2.0.0 新增的两件事：都要你点头

| 动作 | 什么时候发生 | 可逆吗 | 留痕吗 |
| --- | --- | --- | --- |
| 【直接发送给 Agent】 | 你在告警卡片上点一下 | ✅ 写进留言箱有记录；Agent 没读也不影响它跑 | ✅ `injection` 事件 |
| 【一键回滚至拦截点】 | 你点了**并且**确认了计划 | ⚠️ **不可逆**（那之后的改动就没了） | ✅ `rollback` 事件 + `manifest.json` |

- **回滚前一定先出计划** —— 看板上写清楚「将恢复 N 个文件、删除 M 个新建文件」，
  你不点确认就**一个字节都不动**；
- **回滚只覆盖工作目录内的文件** —— 装依赖、推远端、改全局配置这些目录外的操作，
  哨兵**没有**留备份；
- **「写成功」≠「对方读了」** —— 写进 stdin 只是把字节送到了管道，
  Agent 会不会照做，哨兵**不知道**，也不假装知道。
