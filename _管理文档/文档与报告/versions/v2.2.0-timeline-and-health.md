## 1. 红线：这一版一个字都没改

v2.2.0 引入的三样东西都不扩大哨兵的**动作权限**：

| 新能力 | 会不会扩大权限 | 为什么 |
| --- | --- | --- |
| 案发时间线 | **不会** | 纯**读**日志，不写任何东西 |
| 开箱安全体检 | **不会** | 只发两个**极小**的探测请求（`max_tokens=4` / `num_predict=8`） |
| 规则热重载 | **不会** | 只是**换规则**，换出来的规则依然只做「告警 / 挂起」 |

特别说明热重载：它换出来的规则，
**依然不替 Agent 改代码、不擅自终止进程**。
它换的是「**拦什么**」，不是「**能做什么**」。

体检与时间线是**只读**的，这是它们的性质，不是它们的自我克制。

## 2. 任务一：案发时间线复盘

### 2.1 用户真正想知道的是什么

v2.1.0 有了【查看改动】，你能看到 Agent 改了哪些文件。
但**改了什么**和**怎么走到这一步**是两回事：

* 它是在第 3 分钟就偏了，还是第 40 分钟才偏的？
* 那次红线拦截之前，它已经连着跑失败 5 次了吗？
* 中间我手动点过【回滚并重试】吗？点了之后它老实了吗？

挂一整夜的用户早上面对的是**一屏告警**，不是一条故事线。

### 2.2 数据来自四份日志

| 来源 | 产出什么节点 |
| --- | --- |
| `EVENT_JSON` 事件行 | 操作节点（开始目标 / 注入 / 复活 / 回滚 / 热重载） |
| `ALERT_JSON` 告警行 | 异常节点（漂移 / 卡死 / 死循环 / 红线拦截） |
| 安全点服务 | 快照节点（改动的回滚基线） |
| （时间本身） | 相邻节点的**间隔** |

### 2.3 ⚠️ 间隔才是最值钱的那个数

用户问的其实是「**在触发拦截的 10 分钟前，Agent 到底在干什么**」。
而那个答案**不在某一条日志里**，在**两条日志的时间差**里。

所以每个节点都带一个 `gap_text`：
「距上一步 38 秒」「距上一步 12 分 20 秒」。
看板上它就印在时间戳旁边。

### 2.4 节点 ↔ 安全点 ↔ Diff

用户要能回看「在触发拦截前，Agent 改了什么」。三种情况：

| 情况 | `safe_point_id` | `point_id`（Diff 基线） | 能看改动 |
| --- | --- | --- | --- |
| 告警自带快照（守护者在场） | 有 | 回滚点 | ✅ |
| 告警没带快照（守护者缺席） | 空 | **基线** | ✅ |
| 连安全点服务都没有 | 空 | 空 | ❌（**明说没有，不编**） |

⚠️ 守护者缺席时，节点会挂到**基线**上，
但 `safe_point_id` **仍然是空的** ——
快照是「挂起之前」打的，没打过就是没打过，**不能假装打过**。

### 2.5 新日志契约：`EVENT_JSON`

告警说的是「**发现了什么**」，事件说的是「**我们做了什么**」。

```
2026-10-27 21:29:38,564 WARNING EVENT_JSON {"kind": "session_start", "title": "开始目标", …}
```

* 引擎与看板**各持一份同名常量**
  （`src/core/engine.py` 的 `EVENT_MARKER`、
  `src/gui/server.py` 的 `EVENT_MARKER`）——
  和 `ALERT_JSON` / `TOKEN_JSON` 一样的约定；
* ⚠️ **事件不混进告警列表** —— 单独解析。
  混进去的话看板会凭空多出「告警卡片」，用户会以为出了事。

## 3. 任务二：开箱安全体检

### 3.1 检查什么

| 检查项 | 怎么查 | 没配 / 出问题时 |
| --- | --- | --- |
| 本地模型（Ollama） | 发一个 `num_predict=8` 的 ping | **失败** + 告诉用户「没开也能用」 |
| 云端 API 密钥 | 发一个 `max_tokens=4` 的真实请求 | **失败** + 说清缺哪一项 |
| 手机推送（Webhook） | 看配置里有没有真地址 | **警告** + 那句必须说的话 |
| 快照排除规则 | 看 `.gitignore` / `safe_point.excluded_dirs` | **警告** + 说明内置清单兜底 |

### 3.2 ⚠️ 「没配 Webhook」是警告，不是失败

哨兵**照样能干活** —— 规则层不需要联网。
但用户必须知道这件事的后果，所以报告里明说：

> **⚠️ 如果半夜跑挂，您将收不到手机推送！**

### 3.3 体检不该烧显存，也不该烧钱

* Ollama 只发 `num_predict=8` 的 ping；
* 云端只发 `max_tokens=4`；
* `--no-health` / `skip_network` 可以**完全跳过**联网的两项。

### 3.4 体检**绝不**把哨兵启动搞崩

这是一条硬要求：审查侧的异常一律降级（架构红线 R5）。

* `run_health_check()` 逐项 try —— 某一项炸了，其它项照跑，
  炸的那项显示「检查异常」；
* `safe_print()` —— 控制台代码页装不下 `⚠️` 时**降级打印**，
  不抛 `UnicodeEncodeError`；
* 启动路径（`sentinel_entry.py` / `run_with_sentinel.py`）
  把体检整个包在 try 里，失败只打一行日志。

### 3.5 两个入口

| 入口 | 什么时候 | 去哪 |
| --- | --- | --- |
| **启动时** | exe 启动 / 启动器启动 | 终端打印报告 |
| **看板顶栏【体检】** | 用户随时点 | `POST /api/health` → 面板 |

## 4. 任务三：规则热重载

### 4.1 ⚠️ 没有用 `watchdog` —— 如实说明

任务书里写的是「利用 `watchdog` 库（项目初期曾引入过）」。
但翻遍 git 历史能确认的事实是：

* `watchdog` **从来没有**进过本项目的依赖清单；
* `src/core/notifier.py` 里那个 "watchdog" 是「合并摘要看门狗线程」的
  英文词，**不是**那个库；
* 当前环境里**也没装**这个包。

所以热重载走的是项目**一直以来的约定**：`src/tailer.py` 那套
**mtime 轮询**。理由：

1. **零新增依赖** —— 不给分发版 exe 增加一个纯监听用的第三方包；
2. **与既有代码一致** —— 两套监听机制并存只会让人困惑；
3. **打包体积不增** —— 单文件 exe 是要发给别人用的，每 MB 都要算。

代价是**轮询有间隔**（默认 1 秒）。
对「半夜调拦截策略」这个场景，1 秒的延迟完全可以接受 ——
人从改完文件到看到反馈，本来就以秒计。

### 4.2 只换规则引擎

热重载的范围收得死死的：**只重建并热替换 `RuleEngine`**。
通知通道、守护者**不重建** —— 重建它们等于把服务重启一遍，
那就不是「热重载」了。

### 4.3 原子替换

```
1. 读新配置（严格解析）
2. 造新的 RuleEngine
3. 整体换上去
```

审查线程**绝不会**看到「半成品」规则。

### 4.4 ⚠️ 坏配置绝不让规则变空

`load_config()` 读不出来时返回**空字典** ——
而空字典会让规则引擎**一条规则都不剩**，那等于把防线清零。

所以热重载走的是**严格**解析（`_load_strict`）：

| 配置状态 | 行为 |
| --- | --- |
| YAML 非法 | **保留旧规则**，报错：`配置读不出来（ParserError：…），已保留原规则。` |
| 文件是空的 | **保留旧规则**，报错 |
| 文件被删了 | **保留旧规则**，报错 |
| 顶层不是字典 | **保留旧规则**，报错 |

宁可继续用旧策略，也不能让用户一个手滑就把防线清零。

### 4.5 一次保存只提示一次

编辑器保存往往**先清空再写入** —— 文件系统在 mtime 上是**两次**变化。
所以 `ConfigWatcher` 做了**去抖**：
只有版本戳**连续两轮都稳定**时才回调。

⚠️ 这是**实机演示时撞出来的**（单元测试全绿）——
用户改一次配置却在终端看到两条提示，很难不以为自己按了两次保存。

## 8. 已知限制

- **时间线的第一个节点来自启动器** ——
  「开始目标」是启动器写的事件（那一刻引擎还没建起来）。
  **纯看板模式**（不接管 Agent）没有这个节点；
- **时间线依赖日志** —— 没开告警日志就没有时间线；
- **守护者缺席时红线告警不带安全点快照** ——
  这时节点挂到基线上，但 `safe_point_id` 仍然是空的；
- **热重载只换规则引擎** —— 通知通道、守护者要重启才生效；
- **热重载有 1 秒左右延迟**（轮询间隔，可配）；
- **体检的云端检查会发一个真实请求**（`max_tokens=4`）—— 会花一点钱；
- **Ollama 检查需要 Ollama 开着** —— 没开就报「连不上」；
- **钉钉 / 飞书的真实 Token 仓库里仍然没有**；
- **Claude 适配器仍未实机验证**。
