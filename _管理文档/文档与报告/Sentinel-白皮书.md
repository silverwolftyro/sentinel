> **一句话**：哨兵是一个**只读**的「AI 编程助手审计员」——
> 它在旁边看你写的 AI 助手干活，发现它跑偏了、犯错了，**第一时间告诉你**。
>
> **它不碰你的代码。** 除非你**亲手**点头。

## 1. 它是什么

### 1.1 先说个场景

你在让 AI 写代码。它跑着跑着，**忘了你一开始让它干什么**，
开始删你没让它删的文件；或者它陷在某个死循环里，
一小时过去了还在重复同一件事。

这时候你唯一的线索是**滚动条**——
一个几千行的终端日志，你得自己一行行找，
找到那个「转折点」，得花十分钟。

**哨兵做的就是那十分钟里的事。**

它坐在旁边看你那个 AI 的日志，
**每一行都读**，用两套机制判断「这行干的事有没有问题」，
有问题就**立刻**喊你。

### 1.2 它长什么样

一个网页。你在浏览器里开着它，左边是「现在有几路 AI 在跑」，
中间是实时滚动的日志，右边是「现在的状态」。

- **红线告警**（红色）—— 它要做危险操作了，
  比如 `rm -rf`、往外发密钥、写 `.env`；
- **意图漂移**（橙色）—— 它开始跑偏了，跟你最初的要求对不上；
- **Token 计数器**（顶部）—— 这一路烧了多少钱；
- **时间线** —— 这一路发生过什么，按时间排成一条线。

### 1.3 三个关键词

| 关键词 | 意思 |
| --- | --- |
| **只读** | 它**只看你 AI 的日志**。不改你的代码、不改你的配置、不改你 AI 的任何东西。 |
| **实时** | 你的 AI 写一行，它审一行。不是等你跑完了再翻日志。 |
| **需要你点头** | 任何会**动你东西**的操作（回滚、注入提示、挂起进程），**一律先出计划，等你点确认**。 |

## 2. 它能干什么

### 2.1 发现你正在跑的 AI（不用改习惯）

大部分人一开始都以为：要审 AI，**得用哨兵把 AI 重新启动一遍**。
v2.3.0 之后不用了。

哨兵有个**雷达**功能：在看板左边点【**＋ 发现/挂载进程**】，
它会扫出你**已经在跑**的 Codex / MCode / Claude 会话日志，
你点「接入」，它就开始实时审查。

**你的 AI 该怎么跑还怎么跑。** 哨兵是从旁边看着。

### 2.2 挂载会话：连目标都不用你填

接进来之后，哨兵会自己去看这份日志的**开头** ——
你最初给 AI 的那句话一般就写在第一行。

找到了，它就**自动**把它设成「这一路的目标」，
卡片上标一个 **[自动提取]** 告诉你「这个不是我瞎猜的」。

> 找不到？它会**明说**找不到，**绝不编一个**目标出来。
> （编出来的目标会让「跑偏检测」假装在工作，那比没有还糟。）

### 2.3 危险操作：当场拦下

你的 AI 要干危险事了，哨兵会：

1. **先拍个快照** —— 把当前工作目录的状态存下来（这是「后悔药」）；
2. **挂起那个进程** —— AI 停在那里，不会继续闯祸；
3. **给你一张卡片** —— 说清楚它想干什么、为什么危险、人话解释。

然后**你决定**：

- 【**放行**】—— 没事，让它继续；
- 【**查看改动**】—— 先看看它到底改了哪些文件（绿底新增 / 红底删除）；
- 【**一键回滚至拦截点**】—— 把它改乱的东西退回去（**先出计划**，你点头才动手）；
- 【**回滚并重试**】—— 回滚 + 告诉 AI 错在哪 + 重拉一次。
  三个动作合成一次点击（实测 0.019 秒）。

### 2.4 跑偏了：意图漂移检测

你给 AI 的任务是「把这个登录接口的鉴权改成 JWT」，
它跑到一半开始**重构整个目录结构**。

这就是**意图漂移**。哨兵拿你最初的目标当**锚点**，
连续两个窗口判定「跟目标对不上」，就提醒你。

> ⚠️ 跑偏**只告警、不挂起**。
> 因为「AI 想法变了」经常是**对的** —— 守则不擅长判断这个。

### 2.5 半夜叫你起床

哨兵支持手机推送。红线拦截、连续漂移，会推一条**结构化卡片**到你的手机：

- 钉钉 / 飞书 / Server酱 / Bark / 任意 Webhook 都行；
- **60 秒防骚扰** —— 同一件事不会一分钟推十遍；
- **红线级永远直通** —— 合并窗口只影响普通告警。

> 配了真实 Webhook 的话，**启动时会真发一条**（带版本号和你本机 IP），
> 验证外网通不通 —— **不是模拟，手机真的会响**。

### 2.6 早上给你一份晨报

挂一整夜之后，哨兵自动出一份《哨兵值守晨报》：
跑了多久、烧了多少 Token、拦了几次、挽回了多少浪费、用了哪些模型。
落在「晨报归档/」目录里。

### 2.7 它还能自己检查自己

看板上有【**体检**】按钮。点一下，它告诉你：

- 本地模型通不通；
- 云端密钥有没有效；
- **手机推送配了没**（没配会**明说**：「半夜跑挂，您将收不到手机推送！」）；
- 工作目录有没有该排除的规则。

> 它宁可告诉你「你这个配置有问题」，也不让你**以为**自己配好了。

### 2.8 抄近路：不用重启

改了 `config.yaml`？**不用重启哨兵** —— 规则热重载自动生效。
写坏了会**保留旧规则**，绝不让防线清零。

## 3. 它不能干什么（这比上一节更重要）

这一节比上一节长，因为**边界比能力更重要**。

| 它**不会**做 | 为什么 |
| --- | --- |
| **改你的代码** | 它是审计员，不是程序员。改代码是 AI 的活。 |
| **在你不知情时动你的东西** | 回滚、注入、挂起进程 —— **全部**要你先看计划、再点确认。 |
| **自动武装** | 就算它**非常确定**哪个进程是你的 AI，它也只**高亮**那个开关，**绝不替你点**。挂起别人的进程是有代价的，这个决定得你来做。 |
| **随便挂起一个「大概是」** | 反查置信度不够（< 0.75）时，它**禁用**武装开关并明写「[未绑定进程]」。**宁可少一个能力，也不挂错一个。** |
| **把所有告警都推给你** | 60 秒合并窗口，红线直通。防止你被自己的告警淹没。 |
| **替你决定「跑偏了就是错了」** | 漂移**只告警**。AI 改主意经常是对的。 |
| **假装自己很确定** | 提取不到目标就说提取不到；反查不到就说反查不到；体检不通过就说不通过。**它不糊弄你。** |

### 3.1 三条硬红线（R1–R9）

哨兵从 v2.1.0 起定下九条红线，**到 v3.0.0 一个字都没改**。
最要紧的三条：

- **R1 —— 只读**：哨兵不修改、不注入、不改写被监控 Agent 的任何代码、配置或产物；
- **R5 —— 审查侧异常一律降级**：体检、时间线、热重载、启动路径**绝不**抛异常挡住启动；
- **R7 —— 动作要用户点头**：挂起进程、回滚文件、注入提示 —— 全部先出计划、你点头才动手。

> v3.0.0 **没有新增任何写文件 / 改代码 / 终止进程的路径**。
> 「自动提取目标」严格来说只是**把已有的一份信息自动抄进已有的输入框**：
> 读的是你自己的 AI 日志，抄进的是哨兵自己的目标字段，中间没有任何新动作。

## 4. 三分钟跑起来

### 4.1 最快的那条路：先看看它长什么样

**什么都不用装**，下载 `sentinel.exe`，**双击**。

它会进**演示模式**：生成一份模拟日志，打开看板给你看。

> ⚠️ 演示模式**说得很清楚**：
> 看板挂一整条**红色横幅**、背景铺红色斜条纹、
> 左侧会话名变成「**[演示] 默认会话**」，
> 终端大字报后面还跟一段 6 行醒目说明。
>
> **看到的一切都是模拟数据，没有监控任何真实进程。**

### 4.2 真的审一个正在跑的 AI

```bash
# 接管一个真的 mcode / codex / claude
sentinel --agent codex "把这个接口的鉴权改成 JWT"
```

它会把 AI 拉起来，边打印边审。看板在 `http://127.0.0.1:8000`。

### 4.3 审一个**已经**在跑的 AI（推荐）

1. 打开看板；
2. 左边点【**＋ 发现/挂载进程**】；
3. 它扫出你正在跑的会话，点「**接入**」；
4. 完事。**你的 AI 不用重启。**

### 4.4 审一份已有的日志

```bash
sentinel --scan path/to/agent.log
```

### 4.5 多路同时

```bash
sentinel --session-file sessions.json
```

## 5. 怎么配

配置文件默认在 **`config/config.yaml`**（第一次运行会自动从模板生成一份）。
**改动保留你写的所有中文注释**。

### 5.1 最小可用配置

其实**不用改任何东西**就能跑。但下面这几项值得看一眼：

```yaml
# 你的 AI 在哪 —— 让它知道去哪儿找日志
watch_path: "C:/Users/你/.mcode/sessions"

# 任务目标（接管的会话会自动提取，一般不用手填）
task_goal: ""

# 审查级别：info / notice / danger
level: notice
```

### 5.2 模型层：本地还是云端

哨兵用**两层**审查：L1 规则（确定性、免费、毫秒级）+ L2 模型（语义级、准、要花钱）。

**默认走本地**（数据不出本机）：

```yaml
llm:
  provider: ollama
  model: "qwen2.5:7b"
```

想用云端强模型（或者让它在**红线级**时自动升级）：

```yaml
llm:
  provider: openai_compatible
  base_url: "https://api.deepseek.com/v1"
  model: "deepseek-chat"
  api_key_env: DEEPSEEK_API_KEY    # ← 密钥放环境变量，不要写进文件

  routing:
    fallback:
      provider: openai_compatible
      base_url: "https://api.deepseek.com/v1"
      model: "deepseek-chat"
      api_key_env: DEEPSEEK_API_KEY
```

> **密钥一定放环境变量**（`DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` / …）。
> 写进配置文件的话，哨兵**只发到你自己配的那个地址** ——
> 但环境变量更安全，因为配置文件经常被顺手复制走。

**模型层不通会怎样？** 哨兵**不会**因此停止审查 ——
L1 规则层照跑，模型层的事它会在看板上**明说**。

### 5.3 手机推送

```yaml
alert:
  channels:
    - type: webhook
      url: "https://your-webhook-url"
      title: "哨兵"
```

支持：钉钉 / 飞书 / Server酱 / Bark / 任意自定义 Webhook。
写完**重启一下**（或用【设置】页保存，会自动热重载）。

### 5.4 守护者：要不要让它挂你的 AI

```yaml
guardian:
  enabled: true        # ⚠️ 默认是 false —— 要不要开，你自己决定
  intervention_mode: guardian   # guardian = 会挂起；notify = 只告警
```

> ⚠️ **建议先留 `enabled: false` 用几天**，
> 熟悉了它**怎么报警**之后再打开。
> 打开之后也**先只告警**（`intervention_mode: notify`），
> 确认红线拦得准，再改成 `guardian`。

### 5.5 用设置页（更省事）

顶栏点【**⚙ 设置**】—— 那是**独立全屏**的页面（`/settings`，可以单独收藏）：

- 模型路由
- 通知通道
- L1 规则
- 挂载管理

改完点【**保存并应用**】—— 写回 `config.yaml` 并**立刻热重载**。

### 5.6 哪些文件别审

```yaml
rules:
  exclude_paths:
    - "node_modules"
    - ".git"
    - "dist"
    - "*.log"
```

## 6. 手机上看

哨兵有手机推送，你多半会**直接用手机点开看板链接**看。

v3.0.0 专门做了**窄屏适配**（断点 760px）：

- 三栏在手机上改成**上下堆叠**（不是 Tab 切换 —— 少点一次是一次）；
- 按钮最小 **40px** 高（手指点得准）；
- 长路径、长目标**自动换行**，绝不横向撑破；
- 计数器自动重排，不会挤成一团。

> **实测**（390×844 的手机屏）：改前页面宽 584px（一半内容在屏幕外），
> 改后宽 390px = 视口宽，**零溢出**。

## 7. 它怎么判断对错

### 7.1 两层

| | L1 规则层 | L2 模型层 |
| --- | --- | --- |
| 依据 | 写死的正则与红线清单 | 大模型读上下文判断语义 |
| 速度 | 毫秒级 | 秒级 |
| 花钱 | 不花钱 | 要花钱（或本地不花钱） |
| 擅长 | 「这行命令明显危险」 | 「这行代码**看起来**在往外发密钥」 |
| 判不准时 | 宁可漏 | 宁可多问一句 |

### 7.2 大模型不可用时

哨兵**不会**卡住。它会把模型层判定**降级**成「未漂移」，
并在看板上**明说**「模型层不可用」。

> 这是红线 R5 的体现：**审查侧出问题，绝不能挡住审查**。

### 7.3 两种「红」

- **红线**（确定性）—— `rm -rf`、`curl` 外发密钥、读 `.env` 往外传。
  **当场挂起**。
- **漂移**（语义）—— AI 忘了你要干什么。**只告警**。

这个区分很重要：**红线是明确危险，漂移只是「可能不对」**。

## 8. 出事了怎么办

### 8.1 场景一：AI 要删文件

1. 哨兵拍快照、挂起进程、推一条手机告警；
2. 你在手机上看到告警，点开看板；
3. 点【**查看改动**】—— 看清楚它要删什么；
4. 点【**一键回滚至拦截点**】—— 它先给**计划**
   （恢复 N 个 / 删除 M 个），你点确认；
5. 完事。

### 8.2 场景二：AI 卡在死循环里烧钱

1. 哨兵报「意图漂移」，并估出「**挽回 X 万 Token**」；
2. 你点【**复制纠偏提示**】—— 一段中文，粘给 AI，它就知道怎么出来；
3. 或者直接【**回滚并重试**】—— 一次性搞定。

### 8.3 场景三：半夜挂了，早上才看到

看【**晨报**】：跑了多久、拦了几次、烧了多少、用了哪些模型。
再点【**时间线**】—— 那一晚发生过什么排成一条线，
每个节点点进去能回看**当时的改动**。

## 9. 常见问题

**Q：它会看到我的密钥吗？**
A：它读的是 AI 的**日志**。日志里有什么它就看到什么。
所以 —— **别让 AI 把密钥打进日志里**。
哨兵自己也**不会**主动往外发你的密钥（它只连你配的地址）。

**Q：它会不会把我的代码上传到云端？**
A：**默认不会**。默认用本地模型（本机是 NInfer / Bonsai2-27B），数据不出本机。
你主动配了云端 API，它才会发 —— 而且只发**审查需要的那部分**。
【体检】会告诉你现在走的是哪条路。

**Q：它会不会拖慢我的 AI？**
A：不会。审查在**旁路**跑，主循环**绝不被模型调用堵住**。
实测吞吐：**8535 行/秒**，一行不丢。

**Q：我能不能只看，不拦？**
A：能，而且**建议先这样**。
`guardian.enabled: false` 或 `intervention_mode: notify` —— 只告警不挂起。

**Q：它认得 Codex / MCode / Claude 吗？**
A：认得。三种日志格式都有专门的适配器。

**Q：Windows 能用吗？**
A：能，而且主要在 Windows 上开发测试的。

**Q：它多大？装起来麻烦吗？**
A：`sentinel.exe` 单文件，约 **16 MB**，**免安装** ——
不用 Python，不用装依赖，双击就跑。

**Q：数据放哪？**
A：全在你自己的机器上。配置、日志、快照都在项目目录 / `logs/` 下。
**不写你的用户目录**（挂载会话的告警日志落在哨兵自己的 `logs/attached/`）。

## 10. 名词表

| 词 | 意思 |
| --- | --- |
| **红线** | 明确危险的确定性操作（删文件、外发密钥……），会**当场挂起**。 |
| **意图漂移** | AI 忘了你最初让它干什么。**只告警**。 |
| **锚点 / 目标** | 「这一路应该达成什么」。漂移检测拿它当参照。 |
| **守护者** | 能在红线时**挂起** AI 进程的那个角色。要你**手动武装**。 |
| **武装** | 你亲手打开「武装守护者」开关。**没武装 = 只读只报告。** |
| **快照 / 安全点** | 关键时刻的工作目录存档，是「后悔药」。 |
| **回滚** | 把 AI 改乱的文件退回去。**先出计划，你点头才动手。** |
| **复活** | 回滚 + 注入纠偏提示 + 结束挂起进程 + 重拉 AI，四合一。 |
| **注入 / 留言箱** | 把纠偏提示写进 AI 的标准输入；AI 不读 stdin 就落到 `sentinel_inbox.json`，下次启动自动带上。 |
| **Token 审计** | 实时累计这一路烧掉的 Token。 |
| **红线 R1–R9** | 九条硬约束，从 v2.1.0 起**一字未改**。 |
| **演示模式** | 全部是模拟数据。横幅、斜条纹、终端 6 行说明都在说破这一点。 |
| **雷达 / 挂载** | 扫出你**正在跑**的 AI 会话并从旁路接入。 |
| **微批处理** | 日志攒一批推一次（每批 ≤200 行），避免高频推送卡住界面。 |
